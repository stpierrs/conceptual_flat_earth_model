## Long description (use for both stores, trim if needed)

Shane's Model 2.0 is a real-time astronomical simulator built entirely on
Ptolemy's epicycle model — the original Earth-centred system described in
the Almagest around 150 CE.

Every planet, moon, and star you see moving across the sky is driven by
deferent circles carrying epicycles, with parameters measured directly from
observation. No heliocentric constants. No gravitational constant. No AU.
Just the sky doing what the sky does, described the way Ptolemy described it.

**What you can do:**

- Watch the Sun and Moon arc across the vault of heavens from any latitude
- Track Jupiter's four Galilean moons as they orbit on Ptolemaic epicycles
- See Venus change phase as its epicycle carries it around — crescent to full
  and back, exactly as Galileo described
- Follow solar and lunar eclipses with animated demos tied to real dates
- Switch between first-person optical mode (look up at the dome) and
  bird's-eye view of the whole disc
- Adjust observer latitude, date, and time — explore midnight sun, polar
  night, equinox, solstice
- 24-hour flight route overlays showing real southern hemisphere routes
  across the flat disc
- Constellation overlays, celestial navigation stars, and a full starfield
  with precession, nutation, and aberration corrections
- Eclipse demo library: solar and lunar eclipses with ground tracks

**The model:**

The ephemeris runs Ptolemy's Almagest tables — the same ones used by
astronomers from 150 CE to the 1600s. The sun rides an eccentric circle.
Each planet rides a deferent carrying an epicycle. Mercury has the extra
moving-deferent mechanism Ptolemy devised to match observation. The Moon's
model includes the crank mechanism for evection. All parameters come from
the Almagest tables, which came from watching.

This is a conceptual model and educational tool, not a navigation instrument.

## Developer account setup

### Google Play
1. Go to play.google.com/console
2. Pay $25 one-time registration fee
3. Create app → fill in listing → upload AAB → set price → submit

### App Store
1. Go to developer.apple.com
2. Enroll in Apple Developer Program ($99/year)
3. Create app in App Store Connect
4. Upload build via Xcode or Transporter
5. Fill listing → set price → submit for review
